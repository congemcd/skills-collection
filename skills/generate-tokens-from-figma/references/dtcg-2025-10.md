# DTCG 2025.10 Mapping

Default to the Design Tokens Format Module 2025.10 when the user does not specify another format.

Use `.tokens.json` files. Token objects use `$type` and `$value`. Preserve Figma-specific metadata in `$extensions.figma`.

## Variable Mapping

- Figma `COLOR` -> `$type: "color"`
- Figma `FLOAT` -> `$type: "number"`
- Figma `STRING` -> `$type: "string"`
- Unknown Figma types -> keep the raw value and add `$extensions.figma.resolvedType`

Color values must use:

```json
{
  "colorSpace": "srgb",
  "components": [1, 0, 0],
  "hex": "#FF0000",
  "alpha": 1
}
```

Omit `alpha` only when the source did not provide alpha and the value is fully opaque.

## Style Mapping

By default, generate only:

- Color style tokens from single-solid paint styles.
- Text style tokens from text styles.

Only generate effect or grid style tokens when the user explicitly asks for those style types.

Text styles use `$type: "typography"`:

```json
{
  "$type": "typography",
  "$value": {
    "fontFamily": "SF Pro",
    "fontWeight": 400,
    "fontSize": { "value": 17, "unit": "px" },
    "lineHeight": 1.2941176471,
    "letterSpacing": { "value": -0.43, "unit": "px" }
  }
}
```

Use numeric `lineHeight` as a multiplier when Figma provides pixel line height and font size.

## Aliases

Use DTCG curly references for aliases within the same output file, for example:

```json
{
  "dark": {
    "selected": {
      "$type": "color",
      "$value": "{dark.white}"
    }
  }
}
```

When a referenced token is in another output file or cannot be safely referenced, resolve to the concrete value if available and record the original alias under `$extensions.figma.alias`. If no concrete value is available, keep the alias metadata and add a validation warning.
